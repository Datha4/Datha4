## 🚀 Featured Project: 

### 1. Hackathon Project: League of Legends

**Hackathon-LoL** is a serverless data pipeline built around the Riot Games API.  
The goal: provide fun, actionable, and shareable insights for players by combining micro-level game analysis with macro-level performance trends.

🔧 **Main Features:**
- AWS Lambda functions fetching Summoner info, Ranked data, Champion masteries & Match history  
- All data stored as JSON in Amazon S3  
- Smart differential match fetching (only download missing matches)  
- Exposure of all th APIs endpoints combining all player data through API Gateway
- Clean modular Python code (Requests, Boto3, Pandas)
- Using LLM (Claude) to analyze games and share insights from games datas and players
